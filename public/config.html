How to connect Google Sheets — step by step
Session logs and hint logs are written to Google Sheets you own. You do this once per room.
  1. Point it at each Sheet. Open your Google Sheet in a browser and copy the whole address from the address bar. Paste it into the matching “Spreadsheet ID / URL” field below — the page pulls the ID out of the link for you. (Pasting just the bare ID also works.)
    https://docs.google.com/spreadsheets/d/1AbCdEf…long…xyz/edit
  2. Make the tabs. Inside that Sheet, add a tab (the + at the bottom-left) for sessions and one for hints. Type those exact tab names into the “tab name” fields below — capitalisation and spaces must match exactly.
  3. Put the key file on the Pi. Ask whoever set up the Google Cloud project for the service-account key file google-credentials.json. Place it at ~/htm-room-control/google-credentials.json on the Pi, then run sudo systemctl restart htm-room-control.
  4. Find the robot's email. Open that key file in a text editor and find the line "client_email": "…@….iam.gserviceaccount.com". Copy that address.
  5. Share each Sheet with it. In every Google Sheet you referenced above: Share → paste that address → set it to Editor → Send.
  6. Save & check. Click Save at the bottom of this page, then open http://192.168.0.125:4000/healthz in a browser. It should show "sheets": true. If it still says false: the key file isn't in the right place, or a Sheet isn't shared with the robot email.
Everything on the game clock keeps working even when Sheets is not connected — you just won't get the logs.

Hint Groups & Hints

Group your hints (e.g. by puzzle). Give any hint a keyboard shortcut: click its key box, then press the key you want. Click again to change it, right-click to clear. All assigned shortcuts are listed under the Hotkeys tab.
You can also bulk-edit in the Google Sheet's Hotkeys tab (Group | Hint | Hotkey, row 1 = header) and pull it back in with Import from Sheet — review, then Save.
